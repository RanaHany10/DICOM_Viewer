# DICOM Viewer

## Overview
This project provides a full‑featured DICOM Viewer built with PyQt, designed for radiologists, clinicians, and researchers. It supports essential medical‑imaging workflows including: DICOM visualization, multiplanar reconstruction, 3D volume rendering, annotation tools, and a CNN‑powered skin cancer detection module.

## Key Features

### **1. Viewing MRI/CT slices**

### **2. Multiplanar Reconstruction (MPR)**

### **3. 3D Volume Rendering (Surface & Ray Casting)**

### **4. Image enhancement (windowing, sharpening, smoothing, noise reduction)**

### **5. Annotation & measurement tools**

### **6. Integrated CDSS module for skin cancer detection using CNNs**
